# Position Sizing Reference Table

On 0.01 lots EUR/USD (~0.10 USD/pip), stop loss (SL) distance sets your risk:

| SL distance | Risk at 0.01 lots | OK? |
|---|---|---|
| 25 pips | 2.50 USD | ✅ |
| 40 pips | 4.00 USD | ✅ |
| 50 pips | 5.00 USD | ✅ (max) |
| 70 pips | 7.00 USD | ❌ skip or resize |

**Rule: Stop Loss (SL) wider than ~50 pips → the setup is wrong or Isaac skips.** No mental math under pressure.
